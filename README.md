# 🎓 نظام المساعد الذكي للمدرسين (TeacherOS Pro v2.0)

نظام متكامل، فائق السرعة، ومصمم باحترافية للمدرسين والسناتر التعليمية لحل جميع التحديات اليومية (تسجيل الحضور والغياب، الحسابات والمديونيات، المذكرات، طباعة كروت الباركود، والواتساب التلقائي).

---

## 🌟 أبرز التحديثات والمميزات في الإصدار الجديد:

### 1. 🔐 شاشة تسجيل الدخول وإنشاء الحساب (Multi-Teacher Isolation):
- أول ما يفتح النظام تظهر شاشة تسجيل أنيقة:
  - **تسجيل حساب جديد**: كتابة الاسم، رقم الهاتف، مادة التدريس، كلمة السر، وتأكيد كلمة السر.
  - **تسجيل الدخول**: للمستخدمين المسجلين مسبقاً برقم الهاتف وكلمة السر.
- **عزل تام للبيانات**: كل مدرس يمتلك قاعدة بياناته الخاصة ومجموعاته وطلابه دون أي تداخل مع أي حساب آخر.
- إمكانية تسجيل الخروج في أي وقت وتحديث البيانات الشخصية.

### 2. 🛡️ قاعدة بيانات احترافية ونظيفة تماماً (بدون أي بيانات وهمية):
- قاعدة بيانات SQLite احترافية تعمل بتقنية WAL Mode و Foreign Keys لضمان الأمان والسرعة الفائقة.
- **تم حذف جميع البيانات التجريبية والوهمية**؛ يبدأ كل حساب نظيفاً تماماً وجاهزاً للبيانات الفعلية.

### 3. 📱 تصميم متجاوب فائق الأناقة لجميع المقاسات (Responsive Design):
- متوافق 100% مع شاشات الهواتف الذكية (Mobile)، التابلت، اللابتوب، والشاشات الكبيرة.
- شريط ملاحة سفلي مخصص للهواتف الذكية للوصول السريع إلى الحضور، الطلاب، المجموعات، والماليات.
- واجهة عصرية بخط "Cairo" وتأثيرات بصرية حديثة.

### 4. ⚡ نظام الحضور السريع بالباركود والكاميرا:
- مسح باركود كروت الطلاب بالمسدس أو كاميرا الهاتف أو كتابة الكود والضغط على Enter.
- نغمة تنبيه صوتية (Beep Sound) تأكيدية فورية.
- كشف حضور تفصيلي تفاعلي: تعديل فوري لحالة الحضور، المدفوع، المتبقي، الواجب، ودرجة الكويز.

### 5. 🚨 رادار الغائبين ومراسلة واتساب بضغطة زر:
- نافذة مخصصة لمراسلة أولياء أمور جميع الطلاب الغائبين في الحصة مباشرة.
- توليد رسالة واتساب منسقة تلقائياً باسم الطالب وتاريخ الحصة واسم المدرس.

### 6. 💳 كشف حساب وسداد الديون (Debt Settlement):
- نافذة سريعة لتسجيل سداد الدفعات وتحديث فوري لرصيد الطالب.
- ملف شامل لكل طالب يعرض سجل حضوره، درجاته، وسجل مدفوعاته السابقة.

### 7. 🪪 طباعة كروت الباركود و QR Code:
- توليد وطباعة كروت الطلاب مع باركود سريع وكود QR جاهزة للطباعة والتغليف.

### 8. 📊 التصدير والاستيراد والنسخ الاحتياطي:
- استيراد الطلاب من ملف Excel بضغطة زر.
- تصدير كشوف الحضور وقوائم الطلاب إلى ملفات Excel.
- تحميل نسخة احتياطية كاملة (Backup JSON) بضغطة زر للحفاظ على البيانات.

---

## 🚀 طريقة التشغيل:

1. اضغط على ملف **`تشغيل_السيستم.bat`**.
2. أو من موجه الأوامر (Terminal):
   ```bash
   npm start
   ```
3. افتح المتصفح على:
   ```
   http://localhost:3000
   ```
