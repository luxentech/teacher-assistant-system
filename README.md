# 🎓 نظام المساعد الذكي للمدرسين (TeacherOS Pro v2.0 - Static Edition)

نظام متكامل، فائق السرعة، ومصمم بالكامل بملفات **HTML و CSS و JavaScript فقط** بدون أي سيرفر أو قاعدة بيانات خارجية. يعمل مباشرة على أي متصفح، ويُرفع بنقرة واحدة على **Vercel** أو **GitHub Pages**.

---

## 🌟 مميزات النظام الثابت (HTML + CSS + JS):

1. **⚡ تشغيل فوري بدون أي تثبيت:**
   - لا يحتاج Node.js أو بايثون أو أي خادم أو قاعدة بيانات.
   - افتح ملف `index.html` في أي متصفح وسيعمل النظام بكامل طاقته فوراً.

2. **🔐 نظام حسابات متعددة مع حساب للأدمن:**
   - تسجيل حساب جديد للمدرسين بالاسم والهاتف وكلمة السر.
   - حساب الأدمن الرئيسي للتحكم في المنصة:
     - **رقم الهاتف:** `admin`
     - **كلمة السر:** `admin`
   - لوحة تحكم الأدمن: إحصائيات المدرسين، أرباح المنصة، إيقاف/تفعيل الحسابات، وشات مباشر مع المدرسين.

3. **📱 متوافق 100% مع الموبايل والتابلت والكمبيوتر:**
   - تصميم متجاوب فائق الأناقة مع شريط ملاحة سفلي للهواتف الذكية.
   - ماسح باركود ذكي يفتح الكاميرا الخلفية تلقائياً للهواتف المحمولة.

4. **💾 حفظ واسترجاع النسخ الاحتياطية (Backup & Restore):**
   - حفظ كافة البيانات محلياً داخل المتصفح بأمان تام.
   - تحميل نسخة احتياطية كاملة (`.json`) بضغطة زر لنقلها لأي جهاز آخر واستعادتها في ثانية واحدة.

5. **📊 استيراد وتصدير إكسيل (SheetJS):**
   - استيراد الطلاب من ملفات Excel مباشرة داخل المتصفح.
   - تصدير قوائم الطلاب وكشوف الحضور إلى ملفات Excel.

---

## 🚀 طريقة التشغيل:

- **محلياً على جهازك:**
  - اضغط مرتين على ملف **`تشغيل_السيستم.bat`** أو افتح ملف **`index.html`** مباشرة في متصفحك.

- **على منصة Vercel / GitHub:**
  - تم تجهيز المستودع ليتم رفعه مباشرة كموقع Static Web App بدون أي إعدادات إضافية.
